# Contract: 工作区入口与界面行为

覆盖 FR-001–002、FR-007–009、FR-011–015、FR-018–019、FR-023–025；最终以[需求规格](../spec.md)为准。

## 模块与设备切换

沿用当前SwiftUI工作区和语言环境，保留既有默认模块。模块入口使用可换行布局，新增“设备信息 / Device Information”，Android另有“Shell”。iPhone既不显示可执行Shell入口，也不能保留前一台Android的Shell面板为当前模块。

Workspace只有在Store完成选择后绑定子ViewModel。切换、stop、inventory断连/代次变化先撤销子模块revision并取消操作，再绑定新状态；不能只监听按钮事件。相同设备会话下切换模块保留输入/结果，不触发读取或运行。更换会话清空报告、命令草稿、历史和显示缓存。

## 设备信息

顶部展示设备名称与归属、状态和读取/刷新/取消/复制全部。首次只有未读取状态；读取立即反馈。分组显示[字段矩阵](device-information.md)，单值可选择/复制；长指纹/标识可换行或横向滚动，不截断复制值。

完整、部分可用、失败、取消与上次报告均有文字状态，不只依靠颜色。不可用原因贴近字段或类别，恢复入口对应刷新或既有iOS扩展准备。复制全部只取当前选中的一份报告，包含归属、来源时间/缓存说明、单位与不可用原因，不混入后续读取的数据。

## Shell面板

显示目标设备名称和明确标识；多行输入保留原文。“运行 / Run”与“取消 / Cancel”位置稳定，运行和清理期间禁止再次运行。Enter仅换行，只有运行按钮或明确标示的⌘Return才执行；快捷键遵循同一校验路径。

执行前可见“每次使用独立Shell；不支持交互输入”，并可查看30秒、16KiB输入、1MiB输出及历史上限。取消说明简短指出已完成动作不会撤销。连接不可用时保留明确原因和恢复入口，无默认写入示例或自动运行的预置命令。

结果分别展示stdout/stderr、真实退出码或无退出证据的终止原因、耗时、命令及设备归属。两路输出为空显示“无输出”，stderr非空不自动染成执行失败。长输出分页或显示省略提示，提供显式完整复制；ANSI/HTML按普通文本处理。

历史记录点击只查看；“填入命令”只恢复编辑框，运行仍须显式操作。清空按钮旁说明仅清除已完成记录；当前命令仍可继续并生成新记录。发生FIFO淘汰时显示简短提示，不保留被淘汰内容以支持撤销。

Agent显式调用是另一个共享入口：面板呈现相同执行状态，标注“Agent调用 / Started by Agent”，用户仍可取消。运行中来自另一入口的新请求返回busy；Agent不会模拟点击、自动切换当前设备或静默替换编辑框草稿。应用提供本机调用说明及CLI位置，支持复制配置/只读示例。

## 可访问性与布局门禁

所有字段标题、状态、错误、空状态及操作具有简体中文/英文文案。结果为真实文本，支持选中/复制；读取、运行、取消、历史与清空具有可读accessibility label和键盘焦点。沿用项目已验证的控件容器，避免此前会使AX控件不可达的GroupBox包装。

在800×600窗口进行最窄验收（若应用当前minimum更大则使用其既有最小值并记录实际尺寸，不擅自调整全局window minimum）；纵向滚动与可换行模块入口保障核心按钮可达。同时验收常规宽窗口、两种语言、长设备名/长输出。时间指标见SC-003，不能只凭截图声称可交互。
