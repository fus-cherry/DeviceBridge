## User Scenarios & Testing *(mandatory)*

### User Story 1 - 查看当前设备的详细参数 (Priority: P1)

作为连接 Android 或 iPhone 的开发者，我希望在“设备信息”模块中读取设备基础参数、屏幕像素和系统版本，判断设备与目标问题的关联，并将信息复制到问题记录中。

**Why this priority**: 这是本次新增模块的主要目标，应能独立交付，不依赖 Shell 功能。

**Independent Test**: 分别选择一台已授权 Android 和一台 iPhone，打开“设备信息”并读取；与同一设备、同一时刻的可信本机查询或系统信息逐项比对。

**Acceptance Scenarios**:

1. **Given** 已选中连接可用的设备，**When** 首次打开设备信息，**Then** 显示设备归属、可读取类别及“读取信息”入口，不把尚未查询的字段显示为已获取。
2. **Given** 用户点击读取，**When** 请求进行中，**Then** 立即显示读取状态，仍可切换模块或设备。
3. **Given** 设备提供所需数据，**When** 读取结束，**Then** 按基础、系统、屏幕、硬件、内存与存储、电池、连接分组展示数值、单位和采集时间。
4. **Given** Android 的显示分辨率或显示密度被覆盖，**When** 查看屏幕参数，**Then** 区分原始值、覆盖值和当前生效值，不能把覆盖值称为物理屏幕参数。
5. **Given** iPhone 的基础信息可读但扩展信息准备未完成，**When** 读取信息，**Then** 保留可用基础信息，对依赖扩展能力的字段显示具体原因与恢复入口。
6. **Given** 已展示一份报告，**When** 用户刷新或复制全部信息，**Then** 刷新更新采集时间；复制内容含设备归属、分组、单位及不可用原因，并且只复制本次报告。

### User Story 2 - 在当前 Android 上执行命令 (Priority: P1)

作为 Android 开发者，我希望在同一工具内输入设备 Shell 命令，明确看到命令在哪台设备执行、输出和退出码，并能取消等待。

**Why this priority**: Shell 是用户明确请求的另一项独立能力，不能用预置设备信息查询代替。

**Independent Test**: 在指定 Android 上显式执行只读命令，分别验证普通输出、错误输出和非零退出码；切换到 iPhone 后确认没有可执行的 Android Shell 入口。

**Acceptance Scenarios**:

1. **Given** 当前选中可用 Android，**When** 打开 Shell，**Then** 显示当前设备归属、多行命令输入、运行、取消及历史入口；输入本身不会触发执行。
2. **Given** 用户输入含管道、引号、换行或重定向的命令，**When** 点击运行，**Then** 按设备 Shell 语义执行，不能被宿主电脑解释执行。
3. **Given** 命令正常退出或以非零退出码结束，**When** 展示结果，**Then** 区分标准输出和错误输出，同时显示实际退出码、执行耗时、命令内容及设备归属；非零退出不丢失已有输出。
4. **Given** 一条命令尚未结束，**When** 用户再次尝试运行，**Then** 不启动第二条命令，也不在后台自动排队。
5. **Given** 命令正在执行，**When** 用户取消，**Then** 立即显示正在取消并终止本工具持有的执行连接；清理完成后才允许下一条命令，旧结果不得覆盖取消状态。
6. **Given** 用户切换到 iPhone 或失去设备授权，**When** 查看工作区，**Then** Shell 不可执行，并且不会自动重放 Android 上的命令。

---

### User Story 3 - 重用命令并控制历史记录 (Priority: P2)

作为开发者，我希望在当前连接期间复用执行过的命令，而不必重复输入，也不希望命令及其输出被自动上传或长期保存。

**Why this priority**: 已由用户确认，主要改善命令面板的重复操作效率，可在基本执行流程之后验证。

**Independent Test**: 执行多条短命令，选择一条历史记录、清空记录，并验证设备切换及应用退出后的保留边界。

**Acceptance Scenarios**:

1. **Given** 当前会话存在历史记录，**When** 用户选择某条记录，**Then** 能查看原始结果并将命令填回输入框，但必须再次点击运行才会执行。
2. **Given** 用户清空历史，**When** 清空完成，**Then** 当前会话的历史命令及输出不再可见，清空动作本身不执行任何设备命令。
3. **Given** 历史达到保留上限，**When** 新结果完成，**Then** 按最旧优先淘汰记录，仍保留最新结果，并明确告知有旧记录被移除。
4. **Given** 用户切换设备、重新建立连接或退出应用，**When** 进入后续会话，**Then** 不展示或自动恢复前一会话的命令及输出。
5. **Given** 前一条命令更改了目录或临时环境，**When** 用户执行下一条命令，**Then** 新命令从独立 Shell 环境开始，面板明确说明这一行为。

---

### User Story 4 - 正确处理断连、超时和不完整信息 (Priority: P1)

作为同时连接多台设备的开发者，我希望取消、断连及设备切换后不会把旧设备的信息或命令结果错配到新设备，也不会因部分参数不可读而失去全部信息。

**Why this priority**: 这是设备归属可信与现有连接稳定性的验收底线。

**Independent Test**: 在可控制的延迟查询中切换设备、取消或断连，再放行旧请求；验证旧结果没有进入新设备页面，也没有重试设备写入。

**Acceptance Scenarios**:

1. **Given** 正在读取设备 A，**When** 切换至设备 B 后 A 的结果返回，**Then** B 的页面不显示 A 的数据。
2. **Given** Shell 正在设备 A 上执行，**When** A 断连或路由重建，**Then** 当前命令结束为取消、断连或结果未知状态，不自动在恢复后的连接上重试。
3. **Given** 某个设备信息类别被拒绝、超时或数据格式异常，**When** 其他类别可读，**Then** 展示已获取类别并明确标注缺失类别及原因；缺失值不显示为 0。
4. **Given** 请求已取消但外部动作稍后结束，**When** 迟到结果到达，**Then** 不将它报告为本次成功；取消说明不声称撤销已完成的设备副作用。
5. **Given** 命令超过时间或输出限制，**When** 到达限制，**Then** 停止当前执行连接并报告具体限制；如展示已保留的部分输出，必须注明其不完整。

### User Story 5 - Agent调用设备信息与Shell (Priority: P1)

作为使用Agent辅助调试的开发者，我希望Agent能够通过稳定的程序接口获取当前设备及可用能力、读取详细设备信息、执行Android Shell并查询或取消操作，而不必模拟点击界面。

**Why this priority**: 用户明确追加，两个新模块都需要可被Agent复用。

**Independent Test**: 从本机Agent调用入口获取当前设备与会话标识，读取Android/iPhone信息；向Android提交只读命令并查询、取消，再切换设备验证旧会话请求被拒绝。

**Acceptance Scenarios**:

1. **Given** 桌面应用已有可用设备会话，**When** 本机Agent查询设备上下文，**Then** 得到明确设备归属、会话标识与能力状态，不自动切换设备。
2. **Given** Agent显式指定当前设备会话，**When** 请求信息或提交Android命令，**Then** 获得可解析的操作标识、状态、结果及错误，字段和界面遵循同一契约。
3. **Given** 界面或另一个Agent已在执行Shell，**When** Agent再次提交命令，**Then** 返回忙碌，不并行执行、排队或暗中取消前一条。
4. **Given** Agent取消自己的操作或设备会话已变化，**When** 旧操作结束，**Then** 遵守相同清理与归属规则，不重放命令、不将旧结果关联到新设备。
5. **Given** Agent调用已经执行过的命令但响应连接中断，**When** 继续处理，**Then** 可按已知操作标识查询；结果不可获取时明确未知，不自动重新执行。

### Edge Cases

- 同型号的多台设备同时连接，或设备名称相同；始终用设备身份及连接归属区分。
- 屏幕旋转、显示缩放、原始与覆盖分辨率不同；明确各字段的坐标方向和含义。
- 厂商不提供芯片型号、设备电池不返回有效读数、数据卷容量与宣传容量不同。
- Android 不支持某条固定信息查询；iPhone 扩展信息未准备、签名不可用或设备端工具停止。
- 空白命令、包含无效空字符的命令、超长输入、无输出命令、非 UTF-8 输出、多行长输出和非零退出。
- 等待交互输入或无限输出的命令；命令面板不提供交互输入，仍受超时和输出限制约束。
- Shell 中启动了脱离当前连接的后台任务；取消不保证终止这些任务，不掩盖已发生的副作用。
- 取消刚发生在命令完成之前或之后；只允许一个最终状态，下一条命令须等待本地清理结束。
- 正在查看旧报告时刷新失败；如保留旧报告，必须继续保留旧采集时间并标为上次结果。
- Agent与界面同时提交、Agent进程断开、桌面应用重启、旧会话标识复用，以及历史淘汰后查询旧操作。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 在现有设备工作区新增“设备信息”；Android 和 iPhone 均有入口，绑定当前明确选中的设备。
- **FR-002**: 详细信息必须由用户点击读取/刷新，或由本机Agent显式请求获取；首次打开不得显示伪造的样例数据。
- **FR-003**: 报告必须按下表提供字段位置；当前平台或设备未提供的字段显示不可用及原因，不通过型号猜测或宣传数据填充。

| 分组 | 字段与含义 | 平台范围 |
| --- | --- | --- |
| 基础 | 设备名称、平台、厂商、品牌、市场型号、型号标识、产品/设备代号、序列号或设备标识 | 两平台按实际提供情况展示；不要求获取 IMEI、账户等额外身份数据 |
| 系统 | 系统名称、版本、构建版本；Android API 等级、安全补丁日期、构建指纹、内核版本 | 共同字段两平台；Android 专属字段不伪装为 iOS 参数 |
| 屏幕 | 原始屏幕宽高（px）；Android 覆盖与生效宽高、原始/覆盖/生效显示密度（dpi）；iPhone 逻辑宽高、显示缩放、原生缩放、最大刷新率 | “显示密度”不等同于屏幕硬件 PPI；最大刷新率不称为实时刷新率 |
| 硬件 | 芯片型号/厂商、CPU 架构、核心数、支持的指令架构 | 只展示能够可靠读取的值；iPhone 未公开芯片型号时保留限制说明 |
| 内存与存储 | 物理内存总量、可读时的当前可用内存；数据卷总量、已用量、可用量 | 标明单位；可用内存不等于剩余应用配额，数据卷不等于标称闪存容量 |
| 电池 | 电量、充电状态；可读时的供电方式、电池温度和电压 | 未知电量与无电池设备不显示为 0% |
| 连接 | 当前连接方式、当前连接标识、授权/连接状态、采集时间 | 两平台；连接变化后原报告不作为新会话的当前值 |

- **FR-004**: 屏幕必须区分物理/原始像素、覆盖像素、逻辑尺寸与当前生效值；坐标方向须明示，不能将旋转后的宽高差异误报为规格变化。
- **FR-005**: 数值必须附带明确单位并验证合理性；非法负值、溢出、空值和无法解释的数据不得作为正常数值展示。
- **FR-006**: 部分类别不可用时保留已成功读取的数据，显示类别级原因和可执行恢复建议；整体失败时显示明确错误及重试入口。
- **FR-007**: 支持选择并复制单个参数，以及显式复制本次完整报告；报告包含设备归属、采集时间与数据缺失说明。
- **FR-008**: 读取中、未读取、读取成功、部分可用、失败、取消和旧报告状态必须可辨认；设备信息读取支持取消。
- **FR-009**: 只向 Android 提供 Shell 命令面板，且设备必须处于已授权、当前连接可用状态。
- **FR-010**: 命令面板支持多行输入、设备 Shell 的管道/重定向/引号语义；输入文本只能在指定 Android 上执行。
- **FR-011**: 只有用户显式点击运行、使用明确标示的运行快捷键，或本机Agent显式提交执行请求才能发起命令；输入换行、选择历史、查询状态或切换设备不能触发执行。
- **FR-012**: 每次命令保留原始输入、目标设备、开始/完成时间、耗时、标准输出、错误输出和实际退出码；错误输出有内容本身不代表退出失败。
- **FR-013**: 命令面板每次执行建立独立 Shell 环境；不维持工作目录、环境变量或交互程序状态，并在界面解释这一点。
- **FR-014**: 一个面板最多有一条执行或清理中的命令；提供取消，不并发启动下一条，不自动排队、重试或恢复执行。
- **FR-015**: 取消、断连、超时和输出超限与正常退出分别呈现；只有实际退出时才显示退出码，不编造取消命令的退出码。
- **FR-016**: 本规格允许开发者通过界面或本机Agent明确提交命令，进行现有设备 Shell 权限内的操作。系统不得自行获取更高权限、在没有执行请求时自动运行写入命令或设置破坏性快捷操作；取消不撤销已完成的动作，也不保证终止脱离连接的后台任务。
- **FR-017**: 空白、包含无效空字符或超过输入上限的命令在执行前拒绝，并说明原因。
- **FR-018**: 历史记录支持查看结果、恢复命令到编辑框及清空；恢复命令不能直接执行。
- **FR-019**: 历史只保存在当前连接会话内；切换设备、重新建立连接及退出应用均清空，不上传、不写入持久化历史或诊断日志。
- **FR-020**: 所有信息和命令操作必须绑定设备身份与当前连接代次；每个结果归属可核验，设备切换、取消或断连后的迟到结果必须丢弃。
- **FR-021**: 新模块不得阻塞现有连接维护或降低剪切板、截图、文件/图片、内存模块的正确性；冲突时提供忙碌状态，不能暗中变更执行目标。
- **FR-022**: 依赖额外准备的 iPhone 参数应解释其前置条件；基础参数读取不能被扩展能力准备永久阻塞，也不能借读取参数触发剪切板或截图操作。
- **FR-023**: 新界面沿用简体中文/英文切换，字段标题、状态及错误信息可读；长值可选择、复制，键盘可到达主要控件，窄窗口不丢失核心操作。
- **FR-024**: 详细参数、完整标识、命令和输出默认仅供本地当前操作使用；只有显式复制/导出或响应本机Agent的明确调用才能交给对应调用方，不记录到一般诊断日志。工具本身不向远程服务上传，Agent接收后的处理由调用方负责。
- **FR-025**: 默认资源边界为命令输入 16 KiB UTF-8、一次命令 30 秒、合计输出 1 MiB；历史最多 20 条且命令与保留输出合计最多 2 MiB，超限按最旧优先淘汰。界面在执行前可查到这些限制，限制状态不能伪装成成功。
- **FR-026**: 为本机Agent暴露有版本、可发现能力、机器可解析的调用接口，至少支持查询当前设备会话、读取设备信息、执行Android Shell、查询操作状态/结果和取消操作；提供调用说明与只读示例，不依赖界面自动化。
- **FR-027**: 每次设备操作必须显式指定接口返回的设备会话标识；会话变化或应用重启后旧标识失效，返回明确错误，不自动选设备、切换路由或等待扩展准备。
- **FR-028**: Agent和界面复用同一操作入口、会话所有者、Shell互斥、时间/输出上限、清理及结果契约。界面应显示Agent发起的执行及来源；接口不能绕过当前能力或提高设备权限。
- **FR-029**: 返回结构化状态、操作标识、设备归属、时间、字段可用性、两路输出、真实退出码或具体失败原因；不要求Agent解析界面文案。重复请求、响应中断和失效操作标识不得触发自动重放；已淘汰或不可取回的结果明确返回不可获取。
- **FR-030**: 首版接口仅对当前用户配置的本机Agent提供访问，复用运行中的桌面应用；应用未运行或无当前可用会话时明确失败，不新建独立设备控制进程或远程监听服务。

### Key Entities *(include if feature involves data)*

- **设备会话**：设备身份、当前连接、连接代次、可用状态；是读取或执行动作的归属依据。
- **设备信息报告**：所属会话、采集时间、分组参数、各字段的值/单位/可用性与原因；单次报告可部分可用。
- **命令执行**：唯一执行标识、所属会话、原始输入、时间、终止原因、输出及可选退出码；只有一个最终状态。
- **会话历史**：当前会话内有序的命令执行记录及总保留大小，承担查看、恢复输入及淘汰规则。
- **Agent调用**：接口版本、调用标识、目标会话、操作标识及来源；引用既有操作状态，不另建设备会话或保存第二份结果历史。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 在至少一台支持的 Android 和一台 iPhone 上完成设备信息验收；字段表中的每个字段均能展示可核对的值或明确不可用原因，所有已显示数值与独立基准一致。
- **SC-002**: 在已完成必要准备、连接稳定的测试设备上，10 次设备信息读取中至少 9 次于 10 秒内给出完整或部分报告；单次读取超过 20 秒应结束并报告超时/部分结果。初次扩展工具准备耗时单独记录。
- **SC-003**: 运行、读取、取消操作的界面反馈在 200 毫秒内出现；测试中持续输入和切换模块无超过 1 秒的界面无响应。
- **SC-004**: Android 上普通输出、混合两路输出、非零退出、无输出、管道/多行五类只读验收场景均准确呈现命令归属与实际结果。
- **SC-005**: 设备切换、断连、取消、连接重建四类受控竞态各重复 10 次，旧结果错配、取消后显示成功以及自动重放命令的次数均为 0。
- **SC-006**: 正常设备连接下，取消后的本地清理在 2 秒内结束；超过此时间仍须保持可辨认的取消中状态，阻止下一条命令，并作为未满足性能目标记录。
- **SC-007**: 输入、输出、历史条数、历史总大小四类边界测试全部通过；超限均有可辨认反馈，保留资源不超过 FR-025 上限。
- **SC-008**: 新模块完成简体中文、英文、键盘操作及最小支持窗口下的流程验收；现有设备切换和其他模块的回归检查全部通过。
- **SC-009**: 本机Agent无需界面自动化即可完成Android/iPhone信息读取、Android命令提交/查询/取消；与界面并发提交、旧会话请求、应用重启及响应丢失场景均不得错设备执行或重放，结构化结果与界面归属和终态一致。

## Assumptions

- “像素”本轮按屏幕分辨率理解，不包含相机传感器像素、相机能力数据库或硬件跑分。
- 延续现有 Apple Silicon/macOS 14+、Android 11+、iOS 17+ 的产品范围；设备已由开发者授权，所需开发工具可用。
- 默认按需读取（界面或Agent显式调用），不增加周期性硬件监控；电池/存储等动态数据反映采集时刻，不声称实时持续更新。
- iPhone 可用参数可能少于 Android。缺少平台权限或公开数据时允许明确限制，不能以此跳过基础信息与屏幕信息的整体功能设计。
- 首版采用有边界的非交互式命令面板；实时终端输入、持续日志追踪、自动提权、定时执行、跨会话历史和云同步不在本轮范围。
- 上述性能与容量限制是本规格提出的初始验收目标，尚无本功能实测结果；技术方案必须验证可行性后再锁定实现方法。
- 本轮 SpecKit 阶段不提交、推送、安装或发布新版本；功能验收与 Release 发布分开安排。
- Agent接口本轮覆盖新增设备信息与Android Shell；不自动扩大到剪切板、截图、文件传输等既有模块，也不包含远程服务或定时无人值守任务。
