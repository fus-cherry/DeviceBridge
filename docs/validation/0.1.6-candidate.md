# 0.1.6 云端候选验收

状态：开发候选，未发布。不是已签名或已公证的安装包。

## 本批变更

- 当前文件夹名称筛选、目录优先自然排序/文件大小排序；仅处理已加载列表。
- 筛选隐藏当前接收目标时，显示其完整相对路径，避免误以为接收目标改变。
- 初次选择鸿蒙设备进入文件工具，Android/iOS 进入设备信息。
- 同平台切换/暂时断连保留用户选中的工具；跨平台切换重置到相应入口。Android Shell 不遗留到其他平台。
- 入口选择不代表工具已可用，不新增自动扫描、导出、安装或权限绕过。

## 自测循环

环境已列出所有可用技能，没有名为 loop 的技能。使用测试、检查、独立审查、修复与复测循环，不冒称执行了该技能。

1. 文件筛选排序：覆盖空白/大小写/中文、无匹配、自然顺序、未知大小、路径与身份不变。
2. 平台导航：覆盖首次选择、跨平台、同平台保留、Shell 防护、取消选择。检查时修正 SwiftUI initial 回调的旧新值可能相同问题，以独立导航平台状态识别首次进入。
3. 隐藏接收目标：覆盖已加载文件、可见文件、空白筛选、手工路径、目录及空目标。
4. 每部分完成后运行隔离 Swift 回归、Python HDC 回归、两个改动视图的 Swift 语法检查和 diff 空白检查。日志由构建交付保存。

## 发布门槛

- 云端 Linux 隔离测试不能替代完整 macOS 编译及 SwiftUI 类型检查。
- 需要 GitHub macOS CI 对本批提交构建，并在 macOS 窗口/中英文/键盘下检查初始入口和筛选警告。
- 鸿蒙真机的图片、视频、文档可见性、锁屏/拔线/权限拒绝与真实 HAP 安装仍需实机验证。
- APK 文件发送不等于原生鸿蒙安装 APK。继续保留明确提示。
- Apple Developer 会员本身不等于已接入 Developer ID 签名、公证；秘密必须经获批安全途径配置，不能写入源码。
- 本候选不创建标签、不公开 Release；需确定发布方式且完成上述门槛。
