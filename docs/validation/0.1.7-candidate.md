# 0.1.7 候选：设备连接与功能提示优化

本版范围经用户批准，并补充“将不可用连接设备区分开”。基于远端已验证 0.1.6 候选 `1b34c0632a005aad199743b04944dd75947556f3`，仅云端开发，不涉及 Apple 签名接入或本地电脑。

## 变更

1. 功能卡片区分未检查、按需可用、就绪、准备中、处理中、需授权、缺工具、暂不支持及需处理。状态依据已有结构化状态，保留原错误，不根据错误文字猜测原因。文件服务存在不等于每个目录和媒体源已授权。
2. Android/iPhone/鸿蒙独立连接指南，在无设备、侧栏及选择失败时也能查看。指南只展示操作说明，不自行安装工具或改变设备设置。
3. 鸿蒙文件浏览、发送接收、HAP 安装分区。APK 仅复制非原生安装及媒体导出的网络/存储/临时副本风险始终可见，详细说明折叠。
4. 侧栏分为“可尝试连接”和默认折叠的“不可用或需处理”，保留全部设备和真实原因。探测失败自动展开处理组；成功连接行显示实际连接健康状态。“可尝试”不是命令或功能验证成功。

## 测试循环

没有可调用的 loop skill，使用测试、独立审查、修复、复测。独立审查发现成功连接文案可能冲突、失败设备移入折叠组不易找到，均已修复。增加分类和授权优先级测试。

云端针对本批的 Python 接线/布局回归共25项通过；新增10项 Swift 测试待 macOS CI。diff检查通过。

全量 Python 发现运行47项时有2项失败、1项错误、1项跳过：两项包装测试因 Linux 无 `/usr/bin/plutil`，VM 测试因当前无 Swift 工具链；没有隐藏或豁免这些失败。需在 macOS CI 运行适用回归。

## 未验证项

本地没有 Swift/Apple SDK，尚未完成本批 macOS 编译。真实窗口/辅助功能、鸿蒙及其他设备的真机连接权限行为未验证。候选构建不得冒称正式签名或公证；本版不接入 Apple 签名。
