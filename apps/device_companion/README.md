# device_companion

历史 Flutter scaffold，当前原生 macOS 应用不构建或打包此项目。实际内嵌的 iOS runner 位于 `helpers/ios`，由 Mac 应用按当前构建配置的开发团队签名。此旧工程保留空的 `DEVELOPMENT_TEAM`，避免继续绑定历史团队；团队号不是证书或私钥。
